## 🚀 Executar localmente

1. Use um ambiente PHP com servidor Apache e habilite `mod_rewrite`.
2. Instale as dependências do projeto com `composer install`.
3. Configure a URL base e o acesso ao banco nos arquivos de configuração em `application/config/`.
4. Aponte o servidor para a pasta do projeto e acesse a URL local configurada.

> O repositório contém uma aplicação CodeIgniter legada. Revise as dependências e configurações antes de expor uma instância na internet.
